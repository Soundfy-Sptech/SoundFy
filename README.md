# <span style="font-size: 1.1em"> | Tema do Projeto </span>
<span style ="font-size: 1.1em;text-align: justify"> O projeto tem como <b>principal objetivo</b> oferecer uma plataforma de <b>streaming musical</b> onde o usuário pode <b>ouvir</b>, <b>avaliar</b> músicas e acompanhar seu comportamento de consumo por meio de <b>dashboards dinâmicas</b>. <br><br>
O sistema também disponibiliza <b>dashboards exclusivas para artistas</b>, permitindo o acompanhamento do desempenho de suas músicas com base nas avaliações e no engajamento do público, tudo isso através de um site <b>responsivo</b> desenvolvido com <b>HTML</b>, <b>CSS</b> e <b>JavaScript</b> no front-end, <b>Java</b> no back-end e <b>MySQL</b> como banco de dados.
</span>

# <span style='font-size: 1.1em'> | Contexto </span>
<span style ="font-size: 1.1em;text-align: justify"> O <b>SoundFy</b> nasce da necessidade de unir a experiência de escuta musical a uma camada de dados que realmente diga algo sobre o comportamento do ouvinte e o desempenho do artista. Plataformas de streaming tradicionais entregam a música, mas raramente devolvem informação útil de forma acessível — nem para quem ouve, nem para quem produz. <br><br>
A proposta do SoundFy é conectar essas duas pontas: o usuário ouve e avalia as faixas, e essas avaliações alimentam <b>dashboards dinâmicas</b> tanto para o próprio usuário (hábitos de escuta, artistas mais ouvidos, avaliações realizadas) quanto para o artista (média de notas, engajamento, desempenho por música). Até o momento, o projeto <b>não possui nenhuma funcionalidade financeira</b> — o foco está inteiramente na experiência de escuta, avaliação e visualização de dados.
</span>
